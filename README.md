# ✨ CodeCanvas – Personal Portfolio

> **A digital space where code meets creativity.**

CodeCanvas is a modern portfolio website developed to present my academic journey, technical skills, projects, and career aspirations in a clean and interactive way. Instead of simply listing information, the portfolio is designed to tell my story as a Computer Science Engineering student who enjoys building practical and user-friendly web applications.

---

## 🌟 About the Project

This portfolio serves as my personal online identity. It highlights my educational background, technical abilities, featured projects, achievements, and professional contact details. The website focuses on simplicity, readability, and an elegant user experience while maintaining a professional appearance.

---
